# PINHEAD — конструктор печати на одежде

Сайт-конструктор в духе Lacoste Create: клиент выбирает изделие, цвет, загружает картинку, видит превью и оформляет заказ.

## Шаги конструктора

1. **Изделие**: 10 позиций — футболки Regular и Oversize, лонгсливы Regular / Free Fit / Oversize, свитшот Regular, три вида худи Regular и зип-худи на молнии. Список, цены и цвета — в `js/data.js`.
2. **Цвет**: только те цвета, что есть в базе для этого изделия. Фото перекрашивается в выбранный цвет с сохранением складок и швов.
3. **Картинка**: загрузка (PNG/JPG/WEBP/SVG), перетаскивание по изделию, размер, пресеты расположения. Показываем размер печати в см и качество (dpi) и предупреждаем, если картинка слишком мелкая.
4. **Проверка**: итоговый макет, сводка и обязательная галочка «я проверил(а) макет».
5. **Количество**: по размерам (XS–3XL) с оптовыми скидками.
6. **Контакты**: имя, телефон, e-mail, город, адрес, комментарий, согласие на обработку данных.

После оформления клиент видит номер заказа и может скачать итоговый PDF (макет, детали заказа, файл для печати, контакты) и макет в PNG.

## Как запустить

Сборка не нужна: это обычные HTML, CSS и JavaScript.

- **Просто посмотреть:** откройте `index.html` (главная) или `constructor.html` (конструктор) в браузере.
- **Локальный сервер** (так надёжнее):
  ```bash
  python3 -m http.server 8000
  ```
  и откройте http://localhost:8000
- **Выложить в интернет бесплатно:** GitHub → Settings → Pages → Branch: `main`, папка `/ (root)`.

| Файл | Что внутри |

## Частые правки (без программирования)

Всё делается в `js/data.js`.

**Добавить цвет:**
1. В `COLORS` допишите строку: `coral: { name: 'Коралловый', hex: '#FF7F50' },`
2. Добавьте `'coral'` в список `colors` нужного изделия в `PRODUCTS`.

**Убрать цвет, которого нет на складе:** удалите его id из `colors` у изделия.

**Поменять цену:** поле `price` у изделия.

**Скидки:** массив `SETTINGS.discounts` (`qty` — от скольких штук, `percent` — скидка).

## Как добавить или заменить изделие

1. Нужно фото изделия спереди на **чисто белом фоне**. Лучше всего подходит серое или светлое изделие: с чёрного фото складки получаются шумными.
2. Установите пакеты (один раз): `pip install pillow numpy scipy`
3. Запустите скрипт:
   ```bash
   python3 tools/prepare_blanks.py "Лонгслив.png" longsleeve
   ```
   Он вырежет фон, сделает «карту теней» в `img/products/` и обновит `js/blanks.js`.
4. В `js/data.js` добавьте изделие в `SHAPES` (пути к картинкам и зона печати `print`) и в `PRODUCTS` (название, цена, цвета, размеры).
5. Откройте сайт и проверьте пунктирную зону печати на шаге «Картинка». Если она не там, поправьте `x`, `y`, `w`, `h` в `print`.

## Главная страница: частые правки

- **Акцентный салатовый цвет** задан одной строкой в начале `index.html`: `:root{--accent:#9EFF00}`.
- **Форма «Проконсультироваться»** внизу страницы проверяет имя, телефон и согласие и показывает «Спасибо». Чтобы заявки приходили вам, укажите адрес в `LEAD_ENDPOINT` в конце `index.html` (так же, как `orderEndpoint` для заказов).
- **Всплывающая форма «Тираж»** открывается по карточке «03 Тираж»: ФИО, телефон, количество изделий, есть ли макет. Заявки уходят на тот же `LEAD_ENDPOINT` с пометкой `type: "тираж"`. Сама форма — тег `<dialog id="tirageModal">` в конце `index.html`.
- Ссылки на разделы, которых пока нет (блог, оптовый отдел, личный кабинет, каталог подарков и т. п.), стоят как `href="#"`. Замените их на настоящие адреса, когда страницы появятся.

## Места нанесения (грудь, спина, рукав)

На шаге «Картинка» клиент выбирает, где печатать: на груди, на спине или на рукаве. У каждого места своя зона печати (пунктир) и свой реальный размер в сантиметрах — они заданы в `js/data.js`, в `places` у каждого изделия.

Пока у всех мест одно фото — вид спереди. Чтобы при выборе «На спине» показывалась спина:
1. Подготовьте фото: `python3 tools/prepare_blanks.py "Футболка спина.png" tshirt_back`
2. В `js/data.js` у футболки в `places.back` допишите `img: 'img/products/tshirt_back.png',`
3. Откройте конструктор, выберите «На спине» и подгоните зону печати `print` под новое фото.

Для рукава — так же, с именем `tshirt_sleeve` и `places.sleeve`.

## Куда уходят заказы

Пока бэкенда нет, поэтому заказ сохраняется только в браузере клиента (`localStorage`) и клиент видит экран «Спасибо».

Чтобы заказы приходили вам, укажите адрес в `SETTINGS.orderEndpoint`. Сайт отправит туда POST-запрос с JSON: данные заказа, исходная картинка (`image`, base64) и PNG-превью макета (`preview`). Подойдёт, например:
- свой сервер или серверless-функция (Vercel, Netlify, Cloudflare Workers);
- вебхук Make / Zapier / n8n, который уже отправит заказ в Telegram, на почту или в CRM.

## Как устроен код (для изучения)

1. Всё, что выбрал клиент, хранится в одном объекте `state` (`js/app.js`).
2. Любой клик меняет `state` и вызывает `render()`.
3. `render()` перерисовывает превью, шаги, текущий экран и цену.
4. Каждый экран шага — это функция в объекте `views`, которая возвращает HTML.
5. Превью — это SVG. Фото изделия хранится серым: яркость 128 означает основной цвет ткани, темнее — складки, светлее — блики. Функция `tintGarment` в `app.js` умножает выбранный цвет на эту яркость, поэтому складки сохраняются в любом цвете.
6. Картинка клиента кладётся тегом `<image>` и обрезается по зоне печати (`clipPath`). Поверх неё режимом «умножение» ложатся складки ткани, поэтому принт выглядит напечатанным.
